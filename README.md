# Escolar Admin - Sistema de Gestión Educativa

Escolar Admin es una plataforma integral de administración escolar diseñada para gestionar el flujo de información entre administradores, maestros y alumnos. El sistema implementa un control de acceso basado en roles (RBAC) y operaciones CRUD completas para una administración eficiente.

## 🚀 Características Principales

* **Sistema Multi-rol:**
    * **Administrador:** Control total sobre registros. Gestión de maestros y alumnos, visualización de listas con herramientas avanzadas de **Sort** y **Filter**.
    * **Maestro:** Perfil detallado que incluye materias impartidas, ubicación de cubículo y datos de contacto (correo y contraseña).
    * **Alumno:** Registro y consulta de datos académicos.
* **Backend Escalable:** API REST robusta construida con Django REST Framework.
* **Frontend Moderno:** Interfaz reactiva y dinámica desarrollada en Angular 16.

---

## 🛠️ Stack Tecnológico

* **Backend:** Python 3.x, Django REST Framework (DRF)
* **Frontend:** Angular 16, TypeScript
* **Estilos:** CSS3 / Bootstrap (según corresponda)
* **Base de Datos:** SQLite (desarrollo)
